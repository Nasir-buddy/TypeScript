# TypeScript Learning Project

This repository contains my TypeScript learning journey and code examples.

## Getting Started

### Prerequisites
- Node.js installed
- TypeScript installed (`npm install -g typescript`)

### Installation
```bash
npm install
```

## Topics Covered

- Basic Types
- Interfaces
- Functions
- Classes
- Generics
- Modules
- Type Inference
- Type Assertions

## Project Structure

```
/Basic
   └──DataTypes.js
   └──DataTypes.ts
   └── README.md
```

## Running Examples

```bash
tsc filename.ts    # Compile TypeScript
node filename.js   # Run compiled JavaScript
```
